# NEURON — Inside the Living Brain

An interactive 3D educational game about neurons, synapses, learning, memory, attention, sleep and network adaptation.

**▶ Play it here: https://aiongio.github.io/neuron/**

New? Press **▶ DEMO** (top right) to watch the game play itself in about three minutes. Your own progress is untouched.

## Eight modes

| Mode | What you do |
|---|---|
| Explore | Fire a neuron and follow its signal from cell to cell. |
| Learn | Repeat a pattern and watch its pathway physically strengthen. |
| Remember | Reconstruct a whole memory from a single fragment. |
| Train | Practise a key sequence until the circuit can play it on its own. |
| Focus | Keep a task network dominant while distractions compete. |
| Dream | Let recent memories replay and stabilise during accelerated sleep. |
| Repair | Grow and train a new route around an offline relay. |
| Build | Connect concepts through meaningful relationships. |

Modes unlock as the network grows in complexity.

## Controls

- **Mouse / touch:** drag to orbit, scroll or pinch to zoom, click or tap a neuron to inspect it.
- **Keyboard:** `1`–`8` switch modes, `Space` pauses, `Esc` clears or closes, `?` opens the field guide.

## About

- One self-contained HTML file: WebGL graphics, Web Audio sound and the simulation all run locally. No libraries, no tracking, no network requests.
- Progress is saved in your browser. Use Settings → Export / Import to back it up or move it.
- Works offline: download `index.html` and open it in a current Chrome, Edge, Firefox or Safari.

> This interactive simulation simplifies neuroscience for educational purposes. Neural activity, memory percentages, connection strength, attention values, and accelerated processes are game abstractions and should not be interpreted as direct biological measurements or medical information.
